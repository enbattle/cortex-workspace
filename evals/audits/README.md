# Audits

Completeness audits, one dated file each: a fresh agent, given only the plan or specs and the
branch diff, maps every planned item to evidence and checks the docs against
the code (AGENTS.md says when). The first audit (2026-09-24, before this
directory existed) is summarized in the commit "Act on the completeness
audit: a flow bug, stale docs, honest limits".

Audits of the test suites themselves (where their time goes, and which
broken script they would not catch) are dated files named for what they
audit.
